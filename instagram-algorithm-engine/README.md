# Instagram Algorithm Engine

An educational, research-informed simulator for exploring how user signals, content features, freshness, quality, originality, language fit, creator relationships, and experimental time context can affect ranked content.

## Project structure

- `instagram_algorithm/` — scoring models and ranking engine
- `examples/` — demo usage
- `tests/` — automated tests
- `requirements.txt` — Python dependencies

## Important

This is a simulator, not Instagram's proprietary production algorithm. The morning/evening context is an explicit experiment and should not be interpreted as a claim that Instagram uses fixed time multipliers.

## Branch

This project is organized on the `instagram-algorithm-engine` branch of RR-Studios while a separate-repository creation endpoint is unavailable through the connected GitHub integration.
